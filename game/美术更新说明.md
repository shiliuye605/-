# 豚物语 v1.12.0 · 动作与猪种美术更新

双击 `启动游戏.bat` 开始游戏。双击 `美术预览.html` 可以单独查看四方向人物、28 种猪和六类动作；预览页不会读取或修改存档。

## 本次变化

- 28 种猪各有独立透明立绘，区分耳形、毛发、躯干、腹部和花纹。卷毛猪、大肚猪、长白猪、汉普夏白带、巴克夏白蹄、金华两头乌等不再共用四张基础外观。
- 图鉴改为大幅立绘卡片，增加外观特征说明。猪群、喂养、牲畜交易、纪念记录、主线候选、竞争牧场和赛事使用同一套品种素材。
- 人物四方向使用同一站立素材的分层动作，按实际行走距离驱动腿部、摆臂与起伏，停步时平缓归位。地图移动不再额外套一层滞后的坐标过渡。
- 猪的短途移动和去水槽采用连续的起步与减速曲线，步频跟随位移；转身收窄身体后换向。饮水与拱地采用颈部下压，休息逐渐收腿，打滚包含下伏、翻背、回身与站定。
- 管理界面刷新会保留原有猪只与动画状态，避免喂养后猪只换位、动画重头播放。同名猪以品种编号匹配立绘。
- 失去窗口焦点时清除方向按键；打开面板会停止人物行走。系统“减少动态效果”会简化猪只原地动作。

## 原版本与存档

以桌面的 v1.11.3 为基础制作，原版本完整保留。经营引擎、品种数值和六张地图的碰撞配置文件未改变；仍使用 v3 存档格式。

新目录的本地网页可能使用不同的浏览器存储位置。如果新版标题页没有显示原存档，请在旧版“账本 → 存档管理”导出 JSON，再在新版相同位置导入。不要清理旧版浏览器数据。

## 美术来源

新的猪种图集通过 OpenAI 内置 imagegen 工具生成，原图为 `assets/pig-breeds-atlas-v3.png`，实际尺寸 1659 × 948，包含透明背景的 28 种猪。游戏用的独立立绘存放在 `assets/breeds/`。分割时保留透明通道，只裁切空白边界，不重新绘制动物。

每个品种另有独立的屈腿翻背姿势，共 28 张，保留毛色、花纹和毛发特征；通过低伏、翻身和回身的连续过渡接入打滚动作。翻背图集 `assets/pig-roll-atlas-v3.png` 同样由内置 imagegen 生成，实际尺寸 1659 × 948，独立姿势位于 `assets/roll-poses/`。

完整生成提示词见 `猪种立绘生成提示词.txt` 和 `猪只翻背姿势生成提示词.txt`。人物沿用原有 `farmer-idle-v2.png` 的人物身份和服装，由新增动作层驱动。旧图集保留作为版本追溯资源。
