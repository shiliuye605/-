# 本地与浏览器验证

## 不需要浏览器的检查

先执行 `npm run build`，再运行 README 中列出的静态、核心规则与生命周期检查。

`npm run check:desktop` 默认根据 `desktop-baseline.json` 检查 `game/engine.js`、`game/data.js` 和 `game/scene.js` 的原版哈希。若需要进一步验证保留的旧版完整目录，可设置 `TUN_ORIGINAL_DESKTOP_DIR` 为本机 v1.12.0 目录，再运行相同命令。仓库不要求存在作者电脑的私人路径。

## 浏览器检查

`tests/cdp.mjs` 使用 Chrome DevTools Protocol，默认连接隔离浏览器的 `127.0.0.1:9266`，也可通过 `TUN_CDP_PORT` 指定端口。不要使用个人浏览器资料目录；用一个新的临时用户目录启动 Chrome，并启用 `--remote-debugging-port=9266`。

在本项目运行 `npm run dev`，然后分别执行：

```sh
node tests/lifecycle-browser.mjs
node tests/touch-browser.mjs
node tests/pwa-browser.mjs
```

PWA 检查还需要第二个相同测试服务使用端口 `8768`；可设置 `TUN_TEST_PORT=8768` 后启动 `node tests/server.mjs`。测试使用独立页面和演示存档。浏览器测试输出、临时资料目录与任何真实玩家存档不应提交到 Git。

## 截图来源

`docs/images/` 展示的是 1.13.0 构建后的实际页面，使用隔离浏览器新建“演示农场”存档。包含桌面主画面、游戏内图鉴与手机竖屏操作，无真实玩家存档或账户资料。
