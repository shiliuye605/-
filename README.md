# 猪场物语 · 三年育成记

这是一个无需联网、无需安装依赖的单机网页养殖游戏。

当前版本：1.2.0 场景行为修正版。

本次更新：六处场景光圈按背景中的真实入口重新校准，农舍和工坊光圈位于正门、猪圈光圈位于栏门；每头猪首次出现时会固定分配到北圈、中圈或南圈，之后只在该圈的安全内框活动，不会越栏或换圈；人物新增四方向独立站立图集，静止时双脚落地，只有移动时才切换四帧行走图集。1.1.0 的原生 16:9 地图、大字号界面和新版猪只模型仍然保留。

## 开始游戏

双击 `启动游戏.bat`，或直接用 Chrome / Edge 打开 `index.html`。

进度保存在浏览器本地；同一浏览器中最多保留 8 份农场存档。清理浏览器站点数据会删除存档，可在游戏的“账本 → 存档管理”中导出 JSON 备份。

## 操作

- `WASD` 或方向键：在农场行走。
- `E`：进入附近发光地点。
- 鼠标点击发光地点：角色自动走过去。
- 数字键 `1—7`：快速打开猪群、农田、饲料、集市、建造、图鉴、账本。
- `Esc`：关闭当前管理面板。

## 核心规则

- 一年 60 个游戏日，共三年 180 日。行动耗时分为 1/4 日、半日、整日或多日。
- 每 2—3 次行动触发一次不占用时间、但必须处理的事件。
- 第一、二年年底固定进入免计时年市；第三年年底改为比猪大赛并结算结局。
- 结局存档不会被删除。赛后仍可查看和互动，但所有互动都不再推进日程。
- 猪的低心情会导致厌食与成长减速；低健康会生病。病情恶化可能死亡，死猪若两次行动内未处理，会传播疫病。
- 猪圈、农田、工坊、兽医室、围栏和粮仓升级会产生不同的长期增益。

## 猪种与路线

图鉴收录 28 个常见或特色品种，覆盖肉猪、宠物猪、繁育猪三条路线。品种之间的成熟速度、耗料、成长、体重上限、耐病、心情敏感度、繁殖率、产仔范围和售价均不同。

## 美术与声音

农场背景、四名主要角色对话立绘、人物行走与站立图集、猪只图集由 OpenAI 内置图像生成工具制作，随后作为本地素材接入。人物静止与行走状态由游戏自动切换，猪只按固定猪圈播放行走动效。背景音乐与操作音效由浏览器实时合成，不使用外部音频或受版权保护的旋律。
